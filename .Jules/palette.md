## 2024-03-24 - Semantic Active States and Dark Mode Focus Visibility
**Learning:** In dark mode UI sections (e.g., bg-gray-900 like in the Sidebar component), default browser focus outlines are often rendered invisible against the dark background, severely hindering keyboard accessibility. Additionally, merely highlighting active navigation links visually is insufficient for screen readers; they need semantic information.
**Action:** When styling interactive elements in dark mode, always explicitly define `focus-visible` styles with sufficient contrast (e.g., `focus-visible:ring-white focus-visible:ring-offset-gray-900`). For active navigation links, consistently apply `aria-current="page"` alongside visual active states to ensure semantic correctness for assistive technologies.
